# منصة المستر التعليمية (جاهزة للرفع على GitHub Pages)

منصة تعليمية متكاملة مصممة للمدرسين بنظام:
1. **تفعيل المحاضرات بالأكواد (Scratch Codes)** بدلاً من الدفع الإلكتروني.
2. **تقييد الحساب بجهاز واحد فقط (Device Lock)** لمنع مشاركة الحسابات.
3. **الامتحان الإجباري (Prerequisite Quiz)** الذي يمنع فتح المحاضرة التالية إلا بعد النجاح في الامتحان.

## محتويات الملفات:
- `index.html`: واجهة الطلاب (تسجيل الدخول، تفعيل الأكواد، مشاهدة المحاضرات، والامتحانات).
- `admin.html`: لوحة تحكم المدرس (توليد أكواد جديدة بضغطة زر، ومراقبة الطلاب، وفك حظر الأجهزة).
- `data.js`: ملف البيانات (تضع فيه روابط فيديوهات الشرح والأسئلة).

## خطوات الرفع والتشغيل على GitHub Pages:
1. ارفع الملفات الثلاثة (`index.html`, `admin.html`, `data.js`) إلى مستودع (Repository) جديد على حسابك في GitHub.
2. ادخل على **Settings** ثم **Pages**.
3. اختر الفرع **main** واضغط **Save**.
4. سيظهر لك رابط المنصة المباشر خلال دقيقة!

## أكواد تجريبية للاختبار الفوري:
- `VIP-2026` : يفتح جميع المحاضرات.
- `LEC2-100` : يفتح المحاضرة الثانية.
- `LEC3-200` : يفتح المحاضرة الثالثة (وستطلب منك حل الامتحان أولاً).
